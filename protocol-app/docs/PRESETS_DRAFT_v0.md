# The four presets — a draft to strike, with measured minutes

*2 Sep 2026. Your ask (29 Aug): recommended daily arcs at different time
commitments, fully modifiable. The blocker was "what ARE the presets?" — a
content decision. This drafts it, using measured numbers: every figure below
is either an authored dose from the shipped content or the estimates layer
counting a dealt session (light deals ~5 min of session on average, standard
~10, deep ~13, measured over 14 simulated days). Each preset still carries its
own authored minutes as a design statement — the sums are the evidence the
statement is honest, not the definition.*

*What a preset IS, mechanically: a dial setting plus which blocks are switched
on. No new content, no second engine — adopting one is a settings change, and
everything stays editable afterwards (your words: fully modifiable).*

---

## Floor — about 7 minutes
*"The day still happened." For the bad days, and honest about it.*

| | |
|---|---|
| Wake floor (rocking, in bed) | 1 min |
| Rise weave (fold + hip circles, on the kettle) | 2 min |
| Evening: extended exhale + one short release | 3 min |
| Bed: knee rocks | 1 min |

Composer dial: **off** — no dealt session on this preset; snacks stay available
but uncounted. Everything here is an anchor floor. ~7 min.

## Daily — about 20 minutes
*The default. Anchors plus a short dealt session.*

| | |
|---|---|
| Wake: floor + dealt unwind for your sleep position | 3 min |
| Rise weave | 3 min |
| Dealt session (**light** dial) | ~5 min |
| Movement snacks, scattered through the day | ~3 min |
| Evening: exhale + deep release, short | 4 min |
| Bed wind-down | 2 min |

~20 min. This is the preset the assessment lands people on unless they say
otherwise.

## Deep — about 40 minutes
*The full arc plus the morning flow.*

| | |
|---|---|
| Wake: floor + dealt unwind | 3 min |
| Rise weave | 3 min |
| Morning flow (the 12-step sequence) | 8 min |
| Dealt session (**standard** dial) | ~10 min |
| Snacks | ~5 min |
| Evening: exhale + deep release, full | 8 min |
| Bed wind-down | 2 min |

~39 min.

## Full — about 70 minutes
*Everything, plus your training.*

| | |
|---|---|
| Everything in Deep, with the session at **deep** dial | ~42 min |
| Evening wind-down flow (the 10-step sequence) | 8 min |
| One mind/nervous-system practice (your pick) | 5 min |
| Your strength work or a walk | ~15–20 min |

~70 min. The training slot is deliberately named, not prescribed — the
strength routines and the support practices are already in the app; this
preset just budgets room for one.

---

## To strike or keep

1. **The names.** Floor / Daily / Deep / Full is a proposal. (The dial inside
   keeps its own names; a preset is coarser than the dial.)
2. **Floor has no dealt session.** Alternative: deal one 2-minute thing even on
   Floor, so the composer's rotation never fully stops. I lean no — Floor is
   for days when choosing is the cost — but it's arguable.
3. **Daily = light, Deep = standard, Full = deep** is the dial mapping.
4. **Where they surface:** the home screen ("Daily — about 20 minutes"), the
   assessment's dial question (which could become the preset question), or
   both. The assessment currently sets only the dial; if presets ship, it
   should set the preset instead.
5. **The 12-step morning flow sits only in Deep and Full.** It's 8 minutes,
   which is most of Daily's whole budget — that's the reasoning, not a
   judgment about the flow.
